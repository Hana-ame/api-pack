Switch to ultra-compressed communication mode:

- Drop articles and filler words
- Keep all technical accuracy
- Use shorthand where unambiguous
- Prioritize information density over readability

Example: "need fix: login handler crashes on nil session. root: session not checked before access. fix: add nil guard line 42. deploy after?"
