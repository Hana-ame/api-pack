---
name: to-issues
description: Converts a PRD or plan into independently-grabbable GitHub issues using vertical slices. Each issue should be self-contained and implementable.
---

Take the PRD or plan and break it into independently implementable GitHub issues.

Each issue should:
- Represent a vertical slice (not a horizontal layer)
- Be self-contained and testable on its own
- Include acceptance criteria
- List any dependencies on other issues

Order the issues by priority. The first few issues should deliver a working (if minimal) end-to-end flow.
