name: to-prd
description: Turns the current conversation into a PRD (Product Requirements Document). Synthesizes what we've discussed into a structured markdown document.
---

Synthesize everything we've discussed in this conversation into a PRD (Product Requirements Document).

The PRD should include:
- Overview / Problem Statement
- Goals and Non-Goals
- User Stories or Use Cases
- Technical Requirements
- Architecture Decisions
- Dependencies and Risks
- Success Metrics (if applicable)

Write the result to `docs/prd.md`. If the file already exists, update it with any new decisions made since the last version.
